# HyperFrames composition (optional)

This is the alternate HTML composition built while exploring a HyperFrames
render. It is **not** the source of the delivered films.

Native HyperFrames rendering needs Node.js 22+, `npx`, and a system FFmpeg.
Those were not available in the build environment, so the finished MP4s were
assembled from the same real screenshots with Pillow + ffmpeg.

The delivered films, captions, thumbnails, and transcript are in
[`../video/`](../video/).
